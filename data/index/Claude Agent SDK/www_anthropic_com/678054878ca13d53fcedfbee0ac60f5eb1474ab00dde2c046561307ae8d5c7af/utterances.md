# Claude Agent SDK

## Sequence: **3/15**
- Utterance: The Claude Agent SDK is described as a powerful general-purpose agent harness adept at coding and other tasks requiring tools for context gathering, planning, and execution. Its context-management capabilities include compaction, enabling work without exhausting a context window; theoretically this setup should permit useful work for an arbitrarily long time. In practice, compaction alone is insufficient: even Opus 4.5 running in a loop across multiple context windows falls short of a production-quality web app when given only a high-level request such as building a clone of claude.ai. The authors developed an initializer-agent and coding-agent approach to enable effective work across many context windows.
