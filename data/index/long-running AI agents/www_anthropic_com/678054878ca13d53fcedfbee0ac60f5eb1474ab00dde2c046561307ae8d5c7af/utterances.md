# long-running AI agents

## Sequence: **1/15**
- Utterance: As AI agents become more capable, developers increasingly ask them to perform complex tasks spanning hours or days, but consistent progress across multiple context windows remains an open problem. Agents work in discrete sessions, each starting without memory of earlier sessions; limited context windows prevent most complex projects from being completed in one window, so agents need ways to bridge coding sessions. The source compares this to engineers working shifts without remembering the previous shift. The proposed approach first establishes an environment covering all required features, then prompts agents to make incremental progress and leave a clean state: no major bugs, orderly and well-documented code suitable for merging to a main branch, and no unrelated cleanup required before a developer starts a new feature. The research demonstrates one possible harness solution; whether a single general-purpose coding agent or a multi-agent architecture performs best across contexts remains unclear. Specialized testing, quality assurance, or code cleanup agents might perform better on lifecycle subtasks. The demo is optimized for full-stack web app development; generalizing to other fields is future work, and some or all lessons likely apply to long-running scientific research or financial modeling tasks.
