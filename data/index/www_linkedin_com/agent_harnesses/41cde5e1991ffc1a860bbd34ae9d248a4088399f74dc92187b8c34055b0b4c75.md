# Agent harnesses

## Sequence: **5/18**
- Utterance: An agent harness supplies objectives, constraints, guidance and runtime context, connects tools, applications, APIs, data and other services, enables authorized execution and returns observations, maintains task state, history and retrieved information, and enforces access controls, operational limits and human oversight. The harness makes relevant personal context available during reasoning and execution and supports transfers and shared workflows by managing context, permissions, execution and feedback.
