# Agent harness

## Sequence: **8/16**
- Utterance: An agent harness supplies objectives, constraints, behavioural guidance, and runtime context, and connects agents to applications, APIs, data, and services. It enables authorised actions and returns observations to the reasoning process, maintains relevant task state, interaction history, and retrieved information, and enforces access controls, operational boundaries, and human supervision. It supports memory by making relevant context available during reasoning and execution, which can help avoid repeated questions, respect established preferences, recognise recurring mistakes, and maintain continuity across tasks.
