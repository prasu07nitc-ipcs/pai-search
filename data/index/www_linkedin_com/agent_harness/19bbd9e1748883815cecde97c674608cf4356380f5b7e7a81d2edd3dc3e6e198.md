# Agent harness

## Sequence: **8/18**
- Utterance: An agent harness provides instructions and orchestration, including objectives, constraints, behavioural guidance, and runtime context. It connects agents to applications, APIs, data sources, and services, enables authorised actions, and returns observations to reasoning. It manages task state, interaction history, and retrieved information and enforces access controls, operational boundaries, and human supervision. It makes relevant memory available during reasoning and execution. In the integrated PAI architecture, it connects the individual with models and agents through memory, tools, orchestration, and oversight and manages context, permissions, execution, and feedback for transferred context and shared expertise.
